# بوت مراقبة مواعيد فوكس سينما مصر 🎬

بيراقب صفحتين على موقع فوكس مصر:
- `avengers-doomsday`
- `avengers-doomsday-infinity-vision`

وأول ما يظهر أي حفلة جديدة **في الفترة من 24 لـ 31 ديسمبر 2026 بس** (باقي التواريخ بيتجاهلها) (تاريخ جديد، سينما جديدة، فورمات جديد أو ميعاد جديد) بيبعتلك **إشعار على الآيفون** فيه التفاصيل ولينك مباشر لصفحة الحجز.

> ملاحظة: مفيش طريقة تشغّل بوت جوه تطبيق فوكس نفسه على الآيفون، فالبوت بيشتغل على سيرفر مجاني (GitHub Actions) والإشعار بيوصل عن طريق تطبيق **ntfy**.

## التركيب (10 دقايق)

### 1) على الآيفون
1. نزّل تطبيق **ntfy** من App Store.
2. اضغط **+** واشترك في topic باسم سري وطويل، مثلاً: `khaled-vox-7f3k9q2x` (اختار اسم من عندك، أي حد يعرفه يقدر يبعتلك).
3. تأكد إن الإشعارات مفعّلة للتطبيق من إعدادات الآيفون.

### 2) على GitHub
1. اعمل حساب (لو مفيش) وأنشئ repository جديد **Public** (الـ Public مجاني بدون حد لدقايق التشغيل. محتواه مواعيد سينما بس، والـ topic السري بيتخزن في Secrets مش في الكود).
2. ارفع كل الملفات دي بنفس الهيكل (بما فيهم فولدر `.github`).
3. من **Settings → Secrets and variables → Actions → New repository secret**:
   - الاسم: `NTFY_TOPIC`
   - القيمة: نفس الـ topic اللي اشتركت فيه في ntfy
4. من تاب **Actions** فعّل الـ workflows، افتح **VOX monitor** واضغط **Run workflow** مرة يدوي.

### 3) اتأكد إنه شغال
- بعد أول تشغيل هتوصلك رسالة **"✅ بدأت المراقبة"** فيها عدد الحفلات الموجودة حاليًا.
- من هنا كل 10 دقايق تقريبًا بيتشيك، وأي حاجة جديدة بس هتجيلك.
- لو عايز تجرب الإشعار بس: `NTFY_TOPIC=اسمك python monitor.py --test`

## إعدادات اختيارية (متغيرات في ملف `monitor.yml`)
| المتغير | الوظيفة |
|---|---|
| `DATE_FROM` / `DATE_TO` | الفترة المراقَبة بصيغة `YYYYMMDD` (الافتراضي `20261224` → `20261231`) |
| `CINEMAS` | تقصر المراقبة على سينمات معينة، مثلاً `almaza,mall of egypt` |
| `MOVIE_SLUGS` | أفلام تانية (الجزء الأخير من لينك الفيلم) |
| `NOTIFY_EXISTING=1` | يبعتلك الحفلات الموجودة أصلًا في أول تشغيل |
| `FAIL_ALERT_AFTER` | بعد كام فشل متتالي يبعتلك "البوت واقف" (الافتراضي 6) |

## ملاحظات مهمة
- **أنا مقدرتش أجرب البوت على موقع فوكس الحي** من بيئتي (الاتصال بالموقع محجوب عندي). الـ parser متجرب على HTML بنفس شكل صفحة الفيلم (`python test_parser.py`)، لكن لو الموقع بيحجب سيرفرات GitHub أو شكل الصفحة مختلف شوية، هتلاقي الـ workflow بيفشل أو بيرجّع 0 حفلات في الـ logs. ابعتلي الـ log وأظبطه.
- جداول GitHub Actions ممكن تتأخر كام دقيقة، فمتتوقعش فورية 100%. لو عايز أسرع، شغّله على جهاز/VPS صغير بـ cron كل دقيقتين: `*/2 * * * * cd /path && NTFY_TOPIC=... python monitor.py`
- لو الـ repo معملش أي نشاط 60 يوم GitHub بيوقف الجدولة. الـ commit اللي بيحفظ `state.json` بيحصل بس لما فيه جديد، فادخل شغّله يدوي لو وقف.
- التطبيق بيتعامل مع الموقع بشكل لطيف (طلب كل 10 دقايق، حوالي 9 صفحات لكل تشغيل).
